# JavaScript Weather App

A simple weather application built using JavaScript Async/Await and Fetch API to retrieve real-time weather information based on the entered city.

## Features

- Search weather by city name
- Fetch city coordinates using Geocoding API
- Display current temperature
- Handle invalid city names
- Dynamically display weather information

## Technologies Used

- HTML
- JavaScript
- Fetch API
- Async/Await
- Open-Meteo API

## APIs Used

**1. Geocoding API**

Used to retrieve latitude and longitude based on the city name.

https://geocoding-api.open-meteo.com/

**2. Weather Forecast API**

Used to retrieve current weather information using geographical coordinates.

https://api.open-meteo.com/
